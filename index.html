SHIELD

SHIELD — LLM-Powered Mission Assurance for ROS2

Developed SHIELD (Semantic Heuristic Intelligence for Ensuring Legitimate Direction) — a mission assurance framework using a locally-deployed LLM to baseline parameters, monitor commands, and trigger fail-safes in ROS2-based autonomous systems. Presented at ERAU Discovery Day 2025.

Role: Lead Developer
Lab: Space Robotics and Generative Estimation Lab (Dr. Cagri Kilic)
Timeframe: 2025 – Present

Overview: SHIELD uses a locally-deployed large language model to establish a semantic baseline of expected mission parameters, continuously monitor outgoing ROS2 commands against that baseline, and trigger automated fail-safes when anomalous behavior is detected.

Key Contributions:

  • Designed mission parameter baselining pipeline using local LLM inference
  • Implemented real-time ROS2 command monitoring with semantic anomaly detection
  • Developed automated fail-safe trigger system for high-assurance operations
  • Presented as poster at ERAU Discovery Day 2025, Daytona Beach campus

Technologies: Python · ROS2 · LLM (local deployment) · Autonomous Systems · Fail-Safe Design

Skills: Autonomous Systems Security · Mission Assurance · AI/ML Integration · Embedded Robotics

RESEARCH

Sensor Spoofing Detection for Robotic Systems

Lead Developer & First Author of a lightweight EKF-based state-prediction framework to detect GNSS spoofing in autonomous systems. 100% detection rate with sub-second response. Submitted to AIAA SciTech 2026.

Role: Research Assistant – Lead Developer & First Author
Lab: Space Robotics and Generative Estimation Lab (Dr. Cagri Kilic)
Timeframe: Feb 2025 – Present

Objective: Develop a lightweight state-prediction-based framework to detect sensor spoofing in autonomous systems, tested on GNSS spoofing scenarios.

Methodology:

  • Built a 4-state EKF for trajectory prediction
  • Implemented funnel-mode Mahalanobis gating around expected state
  • Created derivative monitor for trajectory acceleration anomalies
  • Simulated GNSS spoofing via in-the-loop simulation to evaluate efficacy

Research Impact:

  • First-author paper submitted to AIAA SciTech 2026
  • Supports resilient GNC for autonomous aerospace systems
  • 100% detection rate with sub-second response times in Monte Carlo simulations

Technologies: Python, NumPy, Simulink, EKF, Monte Carlo simulation

PANDA Avionics System Development

Electronics design engineer developing next-generation liquid rocket avionics for Project MOE. Custom PCB with 12 buses, 16 pressure channels, and 12 solenoid channels for high-altitude launch vehicles.

Role: Electronics Design Engineer
Lab: Experimental Rocket Propulsion Lab (ERPL)
Timeframe: Sept 2024 – Present

System Specifications:

  • 12 total communication buses for distributed system architecture
  • 16 pressure transducer channels for comprehensive fluid system monitoring
  • 12 solenoid control channels for valve actuation and flow control
